# bazis-permit 2.4.0

Requires Bazis 2.4.

## Tools and AI agents

- The package ships `AGENTS.md` (the permission model, setup and rules) and
  `bazis_manifest.toml` for tools and AI agents (see `docs/agents.md` of Bazis).
- New system checks (`manage.py bazis_doctor`):
  - `permit.W001`: `BAZIS_PERMIT_RELATIONS_VIEW_CHECK` is off;
  - `permit.W002`: a JSON:API route does not inherit `PermitRouteBase`, so it serves its
    model without permissions. A route of public data declares `permit_public = True`
    (as the roles route of the package does).
