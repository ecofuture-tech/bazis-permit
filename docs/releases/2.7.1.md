# bazis-permit 2.7.1

Requires bazis 2.7.0. Documentation only; the code is the one of 2.7.0.

## Documentation

The guide (`bazis/contrib/permit/AGENTS.md`) and the manifest answer what the agent of a
trial read the sources for, with tests (`tests/test_guide.py`) where the existing ones did
not cover it:

- the selector `self` and a selector source of its own (`PermitSelectorMixin`,
  `get_selector_for_user`);
- the settings, and how the field permissions show in the API (`readOnly` in
  `schema_update`, an update that ignores a read-only field);
- an item the user cannot see (403) and a missing one (404);
- what the users need to be restricted by permissions (`PermitModelMixin` on the user
  model, a `PermitRouteBase` route set of it: the routes of bazis-users do not check
  permissions);
- another route of a protected model without permissions and what `permit_public`
  does (it only silences `permit.W002`);
- an override of `restrict_queryset` that keeps the permissions (`super()`) and narrows
  them, instead of widening them in code;
- the names of the roles and groups in a data migration (`name_en`, `name_ru`).
