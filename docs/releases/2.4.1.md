# bazis-permit 2.4.1

## Fixes

- **`makemigrations` of a project wrote a migration into the installed package** when the
  languages of the project (`BS_LANGUAGES`) were not English and Russian, for example the
  default English only: the translated field `name` of `Role` and `GroupPermission` had a
  column per language of the project, while the migrations of the package have `name_en`
  and `name_ru`. Now the field always has these two columns, in the order of the project's
  languages (the first one is the fallback): new `translated_languages(*languages)` in
  `bazis.contrib.permit.models_abstract`. Found by the evals of bazis-cli.
