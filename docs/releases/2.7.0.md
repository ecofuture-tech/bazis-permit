# bazis-permit 2.7.0

Requires bazis 2.7.0; the restriction below takes effect with bazis 2.9.

## Security

- **The filter, the sorting and the search of a permit route reached the fields the field
  permissions hide from the user.** Bazis 2.9 restricts them to the LIST schema of the
  route (`JsonapiRouteBase.query_fields`), but the LIST schema of a permit route is built
  per user, so without this change a field a `view` field permission hides
  (`entity.document.field.view.all.description.disable`) could still be found by trial
  with `filter=description=...`, `sort=description`, a search field or a filter through a
  relation of another route (`filter=documents__description=...`). `PermitRouteBase`
  overrides the classmethod `query_fields(user=None, **kwargs)`: the fields the field
  permissions show the user, the union of the fields of the field groups the objects
  match (`perms_field_groups`, in the order of `restrict_queryset`), all the fields if an
  object can match none of them (such an object has no field permissions); the objects a
  relation reaches are still those of `restrict_queryset`. A field hidden from the user in
  every object is now 400 `ERR_FILTER` (`/query/filter`, `/query/sort`), as an unknown
  field, and a hidden search field is left out of the search.

## Known limitation

- The scope is per user, not per object: a field the permissions show in only some
  objects of the list (`field.view.author.description.enable` with
  `field.view.participants.description.disable`), or a field of an object no field
  permission matches, can be filtered, sorted and searched in all the objects the user
  sees. Hide such a field from the route (`fields`) if its values must not be found by
  trial.

## Tools and AI agents

- New system check `permit.W003` (a Warning, `manage.py bazis_doctor`): the model of a
  `PermitRouteBase` route is not a `PermitStructMixin` (`PermitModelMixin`). Such a route
  fails with `AttributeError` (`perms_item_apply`, `get_selector_model`) in its list and
  items, in `included` and in the filters through a relation into the model, as soon as
  the user has a permission on the model. The routes of the `StatusyChildMixin` models of
  bazis-statusy before 2.5 are such routes.
