# bazis-permit 2.11.0

Requires bazis 2.16.

## Breaking changes

- **Custom actions are closed to anonymous users.** A custom action of a `PermitRouteBase`
  (a route of kind `other`: the `http_*` decorators without `kind=`, also the `/_id/` route
  of the core) answers 403 `ERR_FORBIDDEN` to an anonymous user unless it is declared
  `public=True`, whatever the roles for anonymous users, as a create or an update. A public
  action is limited by `BAZIS_THROTTLE_PUBLIC` of the core.
- **`permit.W004` is removed.** The untranslated names of the declared roles and groups
  are listed by `manage.py bazis_messages status` of the core; the check printed them on
  every command, also into the JSON of `bazis_messages`.

## Changes

- **`access_action=` of an action is enforced.** On an action of the collection (no
  `{item_id}` in the path) the permission is checked on the model before the action runs
  (403); on an action of an item it is checked on the item the action takes with
  `set_item` (404 for an item the user cannot view, 403 without the permission).
- **`permit.W007`**: an action of the collection of a `PermitRouteBase` that declares
  neither `access_action` nor `public` (open to every authenticated user).
- The guide describes the custom actions (the gap "public own action").
